# Translation evaluation

Use qualified reviewers across Biblical Hebrew, Bible translation, Afrikaans, poetry,
music and translation consulting. Record the actual role; a programmer's pipeline
check is not a linguistic evaluation. For a stronger later experiment, blind and
randomize candidate presentation and use multiple independent reviewers and Psalms.
The initial comparison report labels its conditions and is not blinded.

Complete every category on a 1–5 scale: 1 poor, 2 substantial problems, 3 usable with
significant revision, 4 good with minor revision, 5 excellent for the stated purpose.

| Category | Assess |
| --- | --- |
| source_meaning_fidelity | Propositions and relations preserved |
| theological_fidelity | No unsupported theological additions or losses |
| lexical_accuracy | Source lexical choices handled responsibly |
| handling_of_ambiguity | Meaningful alternatives not silently erased |
| imagery | Images/metaphors preserved appropriately |
| parallelism | Defensible line relationships retained |
| discourse_progression | Speaker, addressee and progression retained |
| natural_afrikaans | Natural language and intended register |
| poetic_quality | Poetic effectiveness in Afrikaans |
| song_adaptation_suitability | Promise for later musical adaptation; not proven singability |
| decision_transparency | Concise evidence-based notes and visible losses |
| revision_ease | 5 means little human revision; 1 means extensive revision |

`revision_ease` deliberately reverses the direction of raw revision burden so higher
scores consistently mean better outcomes. Record actual revision work and comments
alongside it. Default weights are equal; altered weights must remain recorded, cover
all categories and have a positive sum. A weighted average never cancels a critical
meaning error. Scores are human judgments, not objective proof.

Record critical errors, unsupported additions, omissions, flattened metaphors,
interpretation presented as translation, awkward Afrikaans, poetic gains/losses,
preferred candidate, translator revision and comments. Leave the template unscored
until a person reviews it; null scores cannot be submitted as completed evaluations.
Save separate evaluations for each reviewer. No BLEU or existing translation is used
as ground truth. Any comparison against copyrighted translations needs appropriate
permission. One Psalm and one generation cannot demonstrate general effectiveness.
