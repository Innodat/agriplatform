Its README states that the historical text of Brown, Driver, Briggs and Strong's Hebrew dictionary remains in the public domain. This integration preserves the source files unchanged; application parsing, indexing and presentation are adaptations. BDB transcription is a work in progress. TWOT identifiers are references, not TWOT text.

`manifest.json` records the exact revision URLs, sizes and SHA-256 checksums. `readme.md` is the original upstream notice. Source files are reference data only. Generated application data must retain attribution and identify its source revision.
