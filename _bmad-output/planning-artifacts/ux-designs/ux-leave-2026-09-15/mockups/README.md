# Approved Leave visual references

These are the stable handoff copies of the approved visual studies. DESIGN.md and EXPERIENCE.md remain authoritative; these files are illustrative HTML, not production components or verified browser implementations. Domain examples, fixed calculations and disabled writes remain explicitly illustrative.

The original working studies are retained for provenance. Future keeper corrections belong here and in the design contracts; do not treat a working copy as a competing approved version.

## Accepted written-pattern coverage

The user accepted written rules and existing patterns for routine profile creation, archive confirmations, temporary-approver changes and loading/error variants. Notification and stale-record/upload/partial-load feedback also have approved text presentations. Additional standalone mockups are not required for those variants. This does not waive implementation, integration or accessibility checks.

## Review corrections and remaining limits

The handoff copies include the reviewed error associations, committed allocation announcements and calendar period/selected-date semantics. Static and simulated-handler checks are recorded in the review resolution log; browser and assistive-technology verification remain outstanding.

Known historical simplifications: some older studies retain pixel styling, early form/confirmation labels, approximate date controls or placeholder dialogs. Apply the selected theme and current contract, including automatic return to My Leave after confirmed submission (ADR-0087). Stable links identify approved composition, not approval of every historical interaction or fixture.

Setup readiness predicates and shared visual defaults are approved. Phase 1 implementation readiness is not granted by this inventory.

The funded on-behalf preview does not visualize the initial-unpaid variant added
by ADR-0088. That variant uses the same form and existing employee-response surface
under EXPERIENCE.md, with employee acknowledgement required before final approval.
