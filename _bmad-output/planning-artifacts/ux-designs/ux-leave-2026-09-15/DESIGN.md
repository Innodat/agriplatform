## Brand & Style

Inherit shared visual conventions by reference from
[platform DESIGN.md](../../../../platform/DESIGN.md), currently a draft. Leave's
approved calm, practical visual direction remains in the
[feature specification](../../../../apps/leave/docs/features.md). This document
will capture visual choices from the ongoing screen-by-screen coaching session;
it is not a finalized design or a claim that shared UI already exists.

## Components

The leave-request form will exercise the shared right-side drawer preference on
desktop, with a full page when space is insufficient, including mobile. Validate
width and actual content before treating the shared pattern as proven.
