  persistence, all supported options or actual Leave/People/reference deployment.

  commands supply baseline/actor/operator/membership/reader infrastructure. The current
  Access organization check and KDG prove selected real scopes, not all Leave/People
  capability variants, person links or new session transport. Existing delivered code is
  characterized/reused; it is not reimplemented or blindly accepted for a new consumer.

  private server streaming, new file transport and their adoption tests are remaining
  work. No People or notification runtime is inferred from an owning design document.

  engines. A story consumes an actually completed predecessor; protocol fixtures do not
