## Intent

**Problem:** The approved preparation evidence contract has no executable codec. Consumers need immutable declarations and exact bytes/digests/phase/snapshot checks without mistaking valid records for trusted custody or durable execution.

**Approach:** Implement app-owned standard-library-only result/record/snapshot value codecs against CORPUS_PREPARATION_EVIDENCE, using the existing request parser unchanged. Enforce closed types, byte/depth limits, canonical record spelling, exact UTC/base64/digests/target binding, finite partial/terminal prefixes and create/reuse snapshot rules. Result acceptance additionally binds the complete terminal prefix to independently supplied original request bytes and target descriptor. Encoders validate manually constructed values too. One fixed safe error retains no decoder/caller exception chain. No storage writer, admission verifier, supervisor, target credential parser, SQL/migration, packaging/deployment, owner implementation or live effects. Preserve UX/signup and all existing readiness gates.
