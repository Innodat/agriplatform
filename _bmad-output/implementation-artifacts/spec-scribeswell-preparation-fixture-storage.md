## Intent

**Problem:** The preparation codecs validate declarations but cannot retain local attempt records. The next fixture must prove create-only capture, failure residue and truthful acknowledgement before any executor relies on it.

**Approach:** Close the app-local storage contract and implement a standard-library Linux fixture library using caller-supplied trusted directory descriptors, current-owner0700 root/run directories and0600 regular single-link records. Reserve runs without reuse; validate canonical complete prefixes against independently expected original request/target; persist private temporary bytes, fsync file, publish atomically without replacement, remove only the temporary alias and fsync run directory before acknowledgement. Retain residue and poison the writer on failure; read-only reload checks whole retained prefixes without proving prior acknowledgement. Qualify local synthetic fixtures and injected failures/process crashes only. No SQL, live target/owner admission, execution supervisor, migration, recovery replay or cleanup policy. Preserve existing work, UX/signup and Access/KDG/Leave/factory boundaries.
