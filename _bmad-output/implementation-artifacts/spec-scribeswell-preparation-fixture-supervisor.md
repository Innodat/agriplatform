## Intent

**Problem:** Local preparation codecs/storage have no delivered supervised communication boundary. A synthetic fixture must prove bounded pipes, shared deadlines and truthful child termination before any real executor consumes them.

**Approach:** Close the fixture-only contract and implement one stdlib Linux app-local supervisor/fixed isolated child. Transfer a closed bounded envelope of original request, local target descriptor and already supplied synthetic terminal record prefix; independently validate parent reply binding. Charge all work from public entry to fixed58-second work/60-second total with at most2-second remaining cleanup, cap stdin65536/stdout4096 while transferring, discard stderr, kill/reap only trusted direct child and retain immutable safe unknown/termination evidence. A validated fixture exchange proves declarations/communication only, never database effects, storage acknowledgement or admission. No SQL, credential target parser, storage/owner I/O in parent, production supervisor/integration, arbitrary commands/callbacks/timeouts, retry or live path. Preserve existing code/work, UX/signup and Access/KDG/Leave/factory ownership.
